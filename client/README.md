# 层知 · Anatolume 客户端开发

中文界面品牌为「层知」，英文界面与桌面安装名称为「Anatolume」。标题随界面语言切换；网页及桌面版本显示读取 npm 项目版本，随发布流水线同步。应用标识 `io.github.isunky.humanatlas` 与语言存储键继续沿用；旧最近浏览记录迁移为男性模型记录。男性与女性分别保存最近浏览，模型选择保存到本机并同步到 URL 的 `model` 参数。女性资源、原始署名和改编记录随客户端离线提供，范围见 [女性模型指南](../docs/FEMALE_MODEL.md)。

## 目录边界

- `app/page.tsx`：查看器界面与状态；`app/scene.tsx`：场景生命周期和交互调度。
- `app/core/`：解剖数据类型、分解布局、指针状态、模型解压和搜索工具。
- `app/rendering/`：材质着色器与可见索引批次。
- `client/platform/`：运行环境判断、外部链接与原生更新桥接。
- `client/updates/`：更新状态、下载进度与失败重试；`hooks/use-client-update.ts`：启动检查和偏好存储。
- `client/i18n/`：界面文案、术语草稿和生成来源。
- `client/content/`：中文阅读指南、方位词、常用骨骼说明、观察提示及搜索别名。
- `src-tauri/`：原生窗口、权限和安装配置。
- `public/models/`：男性与女性模型、gzip 资源和来源记录；女性只提供 gzip 几何，客户端构建不携带原始二进制副本。
- `dist/` 与 `dist-client/`：分别为网页和客户端构建产物。

## Windows 构建

需要 Node.js 22.18+、Rust 1.90+ MSVC 工具链、Visual Studio C++ Build Tools 和 Windows SDK。依赖版本由 npm 与 Cargo 锁文件固定；检查脚本使用 Node 原生 TypeScript 支持。

```powershell
npm ci
npm run client:dev
# 生成当前用户安装的 NSIS 安装包
npm run client:build -- --config src-tauri/tauri.local.conf.json
```

产物位于 `src-tauri/target/x86_64-pc-windows-msvc/release/bundle/nsis/`。需要 WebView2；安装程序在缺少运行时时使用联网引导程序。第一次 Rust 构建可能需要数分钟。仅在本机缓存完整且网络不可用时，可以在当前 PowerShell 进程设置 `$env:CARGO_NET_OFFLINE='true'`。

网页命令 `npm run dev` / `npm run build` 继续可用。原生窗口根据屏幕工作区限制初始大小；仅批准来源页面的 HTTPS 外链通过系统浏览器打开。

上述本地构建命令关闭签名更新包产出。官方发布使用同一套固定密钥，默认构建命令需要设置签名环境变量；客户端启动自动检查新版，也可在“关于与致谢 → 应用更新”手动检查。安装版、便携版和 macOS 的更新方式与密钥备份见 [发布与更新指南](../docs/RELEASE.md#客户端自动更新)。

## 主页与浏览布局

主页提供全身结构、骨骼与支撑、内部器官三个入口，实时三维模型可拖动和点击。顶部导航可返回首页、打开 3D 图谱和学习指南。桌面图谱采用左侧探索工具、中央模型、右侧结构详情的布局，模型会随面板和窗口大小重新取景；探索工具可收起。左侧可切换系统与搜索，桌面搜索列表在查看详情时保持可用。

手机使用弹出的探索工具与底部详情卡，选中结构后默认显示紧凑详情，可展开阅读；视角操作与分解滑条保留在底部。分解程度可使用滑条连续调整，桌面另有组装、分离、总览三个快捷档位。

## 整体浏览操作

- 系统名称是标签；开关显示或隐藏该系统，“仅看”关闭其他系统并显示当前系统。
- “全部 / 骨骼 / 器官”切换图层组合；“当前图层”标明默认、预设、自定义、全部隐藏或单独查看结构的状态。手动开关组合若与预设一致，会自动显示对应预设。
- 选中结构即使所属系统已隐藏，也会临时显示，并在图层面板提示；切换图层组合会取消选择。
- 右侧“重置视角”恢复观察位置并停止自动旋转，保留图层、选择和分解程度；高分解程度使用正面视角。
- 底部“恢复全部”恢复默认图层与视角、取消选择、停止自动旋转，并将分解程度归零；默认图层不含体表。

## 结构搜索

搜索结果显示中文名、英文源名、包含的系统、人体左右、网格零件数和图谱源 ID。系统标签来自结果所包含零件的图层分组。左右优先依据源结构名；股骨等明确包含同名左、右零件的成对组合标为“左 / 右”，不会因器官包含左右子结构而给整个器官添加双侧标签。俗称命中时显示实际匹配词，例如“大腿骨”，便于对照“股骨”。左右以人体自身为准。

选择搜索结果会单独显示并高亮结构，打开详情，避免深层器官被外层遮挡；“显示周围结构”可恢复当前图层。方向键导航结果，Enter 选择当前高亮项。搜索框可清空；按 Escape 或点击“关闭搜索”退出。空搜索时将最近查看的最多 6 个结构放在常用结构前，提供独立的清空入口；结构 ID 保存在本机，刷新或重新打开后可继续查看，主页也提供最近探索入口。存储不可用时仍可正常浏览。

## 结构详情与定位

详情面板随内容收紧；说明与观察提示优先展示，“源信息与零件”默认折叠。可收起详情以腾出观察空间，桌面可切换“加宽阅读 / 标准宽度”。收起详情保留选中结构与操作按钮。

- “定位到结构”：相机移向选中结构，保留当前图层和分解程度；周围结构可能遮挡目标，可配合“单独查看结构”。
- “单独查看结构 / 显示周围结构”：仅显示选中结构，或恢复当前图层组合；切换时将分解程度归零。
- “返回整体”：取消选择、退出单独查看并恢复整体视角，保留当前图层与分解程度。
- “关闭详情”：隐藏面板，保留选择；页面保留“查看详情”和“返回整体”入口。

处于定位或单独查看模式时，相机根据详情面板的实际尺寸为选中结构留出可见区域，折叠、加宽和展开源信息时会更新定位视角。

## 中文术语审校

`terms.zh-CN.json` 包含 5,090 个唯一源名称，覆盖模型零件和复合概念。中文名称是规则生成并补充常见词组的完整草稿，尚未经医学专家审校。源 ID、英文名称和模型归属保持不变。

审校时优先修改 `phrases.json` 的完整短语；词根规则在 `lexicon.txt`。随后运行：

```powershell
node scripts/generate-terms.mjs
npm run validate:locales
```

生成会覆盖术语 JSON，勿只修改生成文件而遗漏来源。`terms.metadata.json` 记录生成方法和草稿状态。切换语言不会重建 Three.js 场景；搜索始终支持中文、英文、源 ID。

中文用户可在“关于此图谱”查看阅读指南、方位词和参考链接。9 类常用骨骼的说明与观察提示在 `client/content/zh-CN.ts`，支持其左/右结构；其他结构继续显示已有器官说明或明确标注的系统概述。搜索别名独立于术语表维护，例如“大腿骨”“左大腿骨”“膝盖骨”，不会修改源名称或 ID。新增知识内容为基础学习说明，尚未经医学专家审校；事实核对来源在内容模块的 `CONTENT_REFERENCES`。

## 验证

```powershell
npm run ci:check
cargo fmt --manifest-path src-tauri/Cargo.toml -- --check
```

GitHub Actions 将 CI 检查与版本发布分开。每次推送分支或更新 PR 都会自动运行 CI：执行 `ci:check`，构建 Web、Pages 和桌面前端；不会更改版本、构建安装包或发布。需要发布时，在 GitHub Actions 手动启动 `Manual version, build and release`，选择 main 与 patch/minor/major。工作流会规划并同步版本，运行完整检查，构建 Windows 安装包/便携 ZIP、macOS 通用 DMG 和 Web ZIP，核验版本、源码与 SHA256，随后更新版本提交、创建标签和 GitHub Release，并部署 Web 到 GitHub Pages。Release notes 列出上个版本以来的提交摘要，并附完整比较链接。`0.x` 为测试版。PR 更新会取消过时 CI；发布不会被新 CI 取消，过时源码也不能覆盖新的 main。规则与重试说明见 [自动版本与发布指南](../docs/RELEASE.md)。模型解压兼容原生 DecompressionStream 与 fflate 回退，拒绝截断和错误长度数据。

显隐变化会压紧对应批次的绘制索引，隐藏系统不提交三角形；隔离模式仅提交选中结构，分解视图的点标记也仅绘制可见零件。选中的隐藏系统零件仍按原有规则显示。索引只在批次可见集合变化时更新，分解动画不重复上传索引。为支持恢复显示，每个批次在 CPU 保留一份原始索引；切换系统减少绘制工作，但不释放已加载模型的显存。

CPU 调度按需运行：静止且相机阻尼结束后停止请求动画帧，交互、状态修改、窗口变化和分块加载会唤醒；页面隐藏时暂停。爆炸动画缓存可见零件集合与系统展开方向，仅更新可见零件的位置，选择纹理只在选择/显隐变化时上传。屏幕拾取范围在指针需要时计算并缓存，相机或位置变化后失效。

## macOS 与其他平台

macOS 发布采用 universal 通用 DMG，包含 Intel x64 和 Apple Silicon arm64，要求 macOS 11+。在 macOS 安装 Xcode Command Line Tools、Node 和 Rust 后执行：

```sh
rustup target add aarch64-apple-darwin x86_64-apple-darwin
npm ci
npm run client:build:mac
```

配置采用 ad-hoc 签名（`signingIdentity: "-"`），不需要证书即可构建；尚未经过 Apple 公证，首次打开可能需要在隐私与安全性中允许。CI 会用 `lipo` 验证双架构，并用 `codesign` 验证签名。开发者证书签名与公证仍需 Apple 账户及仓库 Secrets，参见 [Tauri 官方说明](https://v2.tauri.app/distribute/sign/macos/)。编译检查不替代两类真实 Mac 的界面验证。

Windows 便携版由同一次构建的原生 EXE、使用说明和授权文件生成，无需安装程序，模型内嵌，但需要已安装 WebView2，浏览数据保存在本机用户目录。Web ZIP 可直接部署到静态 HTTP/HTTPS 服务。

Android 需要 JDK、Android SDK/NDK，初始化 Tauri Android 工程，补充手机触控、返回键、生命周期与真实设备性能验证。当前未交付 Android 安装包。
