# 层知 · Anatolume 产品需求文档

版本：1.1 · 更新日期：2026-10-23 · 当前应用版本：1.4.0

本文归档此前已落地的产品优化，并规划性能与 3D 视觉体验的后续方向。需求按用户最新决定整理，早期被替换的布局不作为当前要求。

**决策记录：性能优化继续暂缓，3D 外观预设仍为待设计方向。本文不代表批准后续开发或发布。** “已有”表示当前代码或项目文档已包含相关功能，不代表已完成所有设备上的验证。已实施的增量需求在对应章节单独记录。

## 1. 产品定位与目标

层知是中英双语三维人体图谱，支持网页探索与离线桌面使用。用户可以从全身关系出发，逐层查看系统和结构，也可以直接搜索、随机发现并单独观察一个器官。

目标：

- 降低入门成本，让首页、系统浏览、搜索和结构详情形成连续的探索流程。
- 保持界面柔和、整洁，减少重复提示和对核心功能区的占用。
- 保证模型结构、显隐、定位和点击结果一致；优化观感时保留解剖辨识能力。
- 支持男女模型、公共场合的隐私需求和离线学习。
- 明确来源、改编范围与许可，尊重原作者及开放数据贡献者。
- 建立可验证的性能基线，再决定优化投入。

产品用于学习与探索。沿用现有数据范围和审校声明，不新增未经验证的医学准确性承诺。

## 3. 用户场景

| 场景 | 用户目标 | 主要流程 |
| --- | --- | --- |
| 初次探索 | 快速理解人体层次 | 首页 → 全身／骨骼／器官 → 系统列表 |
| 查找结构 | 找到目标并理解位置 | 搜索／列表 → 详情 → 单独查看 → 定位回周围视图 |
| 自由学习 | 发现不熟悉的器官 | 随机探索 → 介绍 → 再换一个／显示周围结构 |
| 公共场合演示 | 默认避免展示敏感结构 | 开启隐私 → 默认展示；主动选择时仍可查看 |
| 男女结构对照 | 切换模型继续探索 | 模型切换 → 当前模型的搜索、图层与最近浏览 |
| 离线学习 | 无网络时继续观察 | 下载客户端 → 使用随包模型；联网后检查更新 |
| 个性化展示 | 选择舒服且清晰的观感 | 3D 外观预设 → 少量微调 → 恢复默认 |

## 4. 已有产品需求与优化记录

### 4.1 首页、品牌与导航

| ID | 需求 | 验收要点 |

| HOME-01 | 全应用统一使用“层知 · Anatolume”，仓库、下载与文档链接使用新地址 | 标题、页眉、关于、打包名称一致；历史发布保留历史名称 |
| HOME-02 | 左上角使用完整的中英文主品牌图片，控制视觉尺寸与裁切 | 英文完整可见，桌面和手机均清晰；不增加不协调的独立“3D”标识 |

视觉原则：沿用浅色背景、柔和灰绿、圆角和克制的强调色。避免扎眼的深绿大色块及多种装饰色同时出现。

### 4.2 男女模型与数据权益

- MODEL-01：页眉支持男性参考模型与女性实验性学习模型切换，两套模型支持网页与离线客户端。
- MODEL-02：搜索、系统列表、随机候选与最近浏览基于当前模型，避免跨模型引用失效的结构 ID。
- MODEL-03：切换模型时清理不再适用的选择和随机记录，保留已约定的本机偏好与分模型浏览记录。
- MODEL-04：保留 BodyParts3D、HRA、Human Atlas Enhanced 的来源、原作者、许可及改编记录；感谢 [PrejudiceNeutrino](https://github.com/PrejudiceNeutrino)。
- MODEL-05：保留女性模型的估算配准、范围限制和未经独立审校的声明，不将视觉美化解释为解剖准确性提升。

验收：两套模型均可加载、切换、搜索及离线查看；许可文件随部署和打包保留，关于及 README 的来源链接可访问。

### 4.3 系统列表与下级结构

- LIST-01：第一级为系统，使用单一色系图标；第二级为下级结构，不增加图标。
- LIST-02：支持展开系统、浏览下级列表和筛选结构。名称、数量、仅看操作、显隐开关层级清楚。
- LIST-03：系统和下级结构均可控制显隐；“仅看”保留明确的系统级操作。
- LIST-04：数量反映实际显示状态，部分显示与全部显示可区分。
- LIST-05：筛选框、展开区域和滚动内容不得穿透或相互覆盖；长名称避免挤压开关。
- LIST-06：桌面和手机的点击区域、滚动及展开体验一致；键盘可操作，开关有名称与状态。

验收：展开、筛选、系统开关、单项开关、仅看及恢复全部与模型实际显示一致；中英文长名称、空筛选结果和手机窄屏无布局遮挡。

### 4.4 结构详情、定位与镜头

- CAMERA-01：选中结构后复用介绍与最近浏览逻辑，支持单独查看和显示周围结构。
- CAMERA-02：“定位到结构”使用平滑动画。单独查看时恢复此前较全景的周围视图，并高亮当前结构。
- CAMERA-03：定位按钮保持原操作名称，不额外显示“已定位”。
- CAMERA-04：斜视、正面、侧面、背面平滑切换；在单独查看模式下同样可用，并围绕当前结构合理构图。
- CAMERA-05：拖动、缩放等主动操作可接管镜头，避免动画与手势争夺控制；遵循减少动态效果偏好。
- CAMERA-06：结构详情提供“隐藏当前结构”。隐藏当前选择的全部模型零件，清除选择并关闭详情；单独查看模式下恢复周围图层，保留目标的隐藏状态及其他结构的显隐设置。从列表重新显示、主动搜索或重新选择目标时允许恢复查看。

验收：连续切换视角无跳变，目标不会移出视野；隔离后定位可恢复上下文，隐私规则与显隐逻辑保持一致。

### 4.5 自动旋转

- ROTATE-01：同一按钮提供启停操作与简易下拉设置，支持旋转方向及连续速度滑条。
- ROTATE-02：速度随滑条线性变化，最高速度对应此前普通速度的 10 倍；界面以百分比表达，100% 为最高，不显示“10 倍速”。
- ROTATE-03：单独查看结构时可用，围绕目标旋转；保留现有分离／总览模式的适用限制。
- ROTATE-04：下拉框不遮挡核心操作，手机端可触控，速度与方向变化即时生效。

验收：不同位置的速度差异明确且连续，方向切换正确，开关与实际旋转状态一致；不因新增外观设置改变速度语义。

### 4.6 分离与零件总览

- EXPLODE-01：由完整组装平滑过渡到按系统分离，再到零件总览。
- EXPLODE-02：主要系统按实际宽度紧凑排开，保留系统内部相对关系。间隔适度，避免过宽导致模型过小。
- EXPLODE-03：镜头随布局合理适配，显隐变化后重新计算布局。
- EXPLODE-04：现有系统间距参数为 0.025 模型单位，作为当前基线，后续调整需以截图对比确认。

验收：正面系统分离视图无主要横向挤压，间距紧凑，恢复组装位置正确。横向排列不承诺在侧面投影下完全无重叠。

### 4.7 随机器官探索

- RANDOM-01：右上角入口和结构介绍中的“再换一个”共用逻辑；进入图谱后隔离完整器官、自动聚焦并打开介绍。
- RANDOM-02：固定候选以概念 ID 匹配当前模型，包含该完整概念的全部有效零件，按 ID 去重；左右成对器官按单侧抽取。
- RANDOM-03：共同候选包括心脏、脑、肝、胃、脾、胰腺、胆囊、气管、食管、膀胱、小肠、大肠、左右肺、左右肾和胸腺；男性补充左右睾丸、前列腺，女性补充左右卵巢、子宫。
- RANDOM-04：从有效候选等概率抽取，排除当前器官及上次随机结果。排除后无候选但原候选不为空时放宽排除条件，优先避免重复上次结果；仅一个有效候选时允许重复，无有效候选时禁用。
- RANDOM-05：模型加载完成且无错误后启用；模型切换重建候选并清理随机记录。遵循隐私规则，不自动轮播、不新增接口或随机记录持久化字段。

验收：两套模型的候选 ID、零件完整性及性别专属范围正确；验证连续抽取、双候选边界、空候选、单候选与隐私过滤。

### 4.8 统一隐私模式

- PRIVACY-01：男女模型共用隐私设置，开启后在默认视图和随机探索中隐藏各模型定义的敏感结构。
- PRIVACY-02：主动搜索、从列表打开系统／部件、主动单独查看时允许访问；显式访问不会关闭隐私设置。
- PRIVACY-03：恢复默认视图时重新应用隐私规则，不把一次主动查看变成永久全局豁免。
- PRIVACY-04：底部状态栏用图标显示状态；鼠标悬浮解释当前设置，点击跳转到设置位置。说明不是仅在切换状态时出现的 toast。
- PRIVACY-05：触屏和键盘用户能获得同等状态说明；不依赖颜色或悬浮才能理解状态。

验收：默认隐藏、主动查看、系统显式开启、随机排除、恢复默认和模型切换形成闭环；图标状态与设置一致。

## 5. 性能优化路线（暂缓）

### 5.1 已有基础与测量缺口

当前已有按需渲染、后台暂停、网格合批、隐藏结构索引过滤和隐藏批次跳过绘制。点击拾取先进行包围盒筛选。

| 模型 | 零件 | 三角形 | 清单中的解压后几何字节数 |
| --- | ---: | ---: | ---: |
| 男性 | 2,234 | 2,288,268 | 59,546,744 |
| 女性 | 2,245 | 2,437,148 | 62,108,560 |

以上为现有模型清单统计，字节数不等于下载量、CPU 内存或显存。现阶段没有统一设备上的帧耗时、GPU 时间和内存峰值对比，不承诺提升比例。

### 5.2 方案、收益与负面影响

| ID | 方案与预期收益 | 负面影响 | 控制要求 |
| --- | --- | --- | --- |
| PERF-01 | 建立加载、旋转、点击与内存测量基线 | 调试统计本身可能干扰结果 | 只在测量模式启用；记录设备、分辨率、缓存状态和采样方式 |
| PERF-02 | 减少重复几何／索引复制，降低内存峰值 | 原始几何承担拾取，错误释放会导致无法选中或偏移 | 先梳理所有权；保留拾取必要数据，检查模型切换与资源释放 |
| PERF-03 | Worker 处理解压及几何合并，减少主线程卡顿 | 复制增加内存和耗时，旧模型任务可能污染新场景 | 使用可转移缓冲区；支持取消、异常回退与结果归属校验 |
| PERF-04 | 分阶段加载，优先可见／目标结构 | 初始模型不完整，搜索需要等待；总加载不一定更快 | 区分可操作与全部完成；目标优先加载，错误可重试 |
| PERF-05 | 掉帧时降低绘制分辨率，改善 GPU 像素负担 | 细神经／血管变模糊，清晰度跳变，自动旋转可能长期低清 | 设置下限及切换延迟；停止后恢复，截图完整清晰度；确认瓶颈适用 |
| PERF-06 | 空间索引／BVH 加速点击 | 额外依赖、构建时间及内存；不能直接改善旋转帧率 | 先证明拾取瓶颈；验证隐藏、分离、隔离及最近命中结果 |
| PERF-07 | LOD 降低远处结构面数 | 轮廓改变、细结构断裂／消失、细节切换跳变 | 最后评估；优先大型结构，近距离及选中目标保留完整细节 |

恢复实施后的建议顺序：PERF-01 → PERF-02／03 → 按测量结果选择 PERF-04／05／06 → 最后评估 PERF-07。不要同时替换所有渲染路径，否则难以归因。

### 5.3 测量与验收

- 在相同设备、模型、视口、显示密度与操作路径下，对比修改前后；男女模型分别记录。
- 覆盖冷／热加载、全身旋转、单器官旋转、系统显隐、分离／总览、连续点击、模型反复切换及后台恢复。
- 记录首次可操作时间、全部加载时间、主线程长任务、帧耗时中位数与 P95、点击响应及可测内存峰值；注明工具限制，不以 JS 堆代替显存。
- GPU 专项优化应记录 GPU 时间（环境支持时）；CPU 专项优化应记录任务耗时，避免仅用平均 FPS 判断。
- 最低门槛：目标瓶颈有可重复改善，结构完整性、拾取准确性及核心交互不退化。量化目标在基线建立后确定。
- 对暂时降清方案，保存动态与静止画面对比，重点检查细血管、神经、骨缝和选中边界。

## 6. 3D 视觉与个性化配置（待设计／验证）

### 6.1 当前问题与设计原则

当前背景、灯光和材质参数基本固定；不同系统多采用相同表面参数，选中时明显偏青绿。可通过材质差异、照明和背景增强层次。

- 默认保持浅色、柔和、清晰，延续现有界面风格。
- 先提供预设，再允许少量微调；不向普通用户暴露金属度、曝光算法等技术参数。
- 保留器官原色与常用系统识别线索，材质变化不制造虚构组织细节。
- 先使用现有灯光与材质路径，不因视觉配置默认启用昂贵后处理。

### 6.2 三个外观预设

| 预设 | 背景 | 材质与照明 | 使用目的 |
| --- | --- | --- | --- |
| 清晰学习（默认） | 浅雾灰 | 哑光、均衡柔光，保留经典系统配色 | 日常学习、观察结构 |
| 柔和展示 | 暖白 | 适度柔润、柔和照明，降低过强饱和度 | 截图、课堂展示 |
| 深色观察 | 深石墨 | 控制暗面、适度轮廓光，匹配高亮和标记 | 骨骼与单器官观察 |

预设名称、具体色值和滑条范围在视觉原型中确认，当前不是最终参数。

### 6.3 配置要求

| ID | 配置 | 行为与风险控制 |
| --- | --- | --- |
| VIS-01 | 背景：浅雾灰／暖白／深石墨 | 与场景底座、标记、高亮协调；深色 3D 背景不自动等同全站深色主题 |
| VIS-02 | 质感：哑光—柔润 | 骨骼、肌肉和器官采用适度差异；限制高光，不把软组织做成金属或塑料 |
| VIS-03 | 灯光：柔和／立体，亮度微调 | 避免过曝、黑死暗面与色偏；切换视角后结构仍可辨 |
| VIS-04 | 配色：经典／柔和 | 保留动脉红、静脉蓝等线索；列表图标仍保持单一色系，不恢复多彩装饰 |
| VIS-05 | 选中：柔和强调／保留原色 | 降低整体染色强度；任何背景下均可辨识目标；不默认依赖描边后处理 |
| VIS-06 | 底座显示／隐藏 | 全身展示可保留，单器官观察默认隐藏；用户覆盖规则需在原型中确认 |
| VIS-07 | 本机偏好与恢复默认 | 网页、客户端共用配置结构；默认跨男女模型复用，模型切换不重置外观；存储异常回退默认 |

### 6.4 设置交互

1. 从现有设置所在面板进入“3D 外观”，具体入口在原型中确定，不挤占核心探索工具。
2. 顶部三张小预览卡选择预设，选择后即刻预览；卡片显示选中状态，键盘可操作。
3. 下方折叠“自定义”，提供背景、亮度、质感、配色、选中效果和底座；滑条有可读名称和值。
4. 修改后标为“自定义”，不额外新增一个预设卡；再次选预设覆盖本节外观参数。
5. 自动保存本机偏好，提供“恢复默认”；仅恢复外观，不改变隐私、语言、模型选择、结构显隐或旋转速度。

偏好保存需处理旧数据迁移、无效值与存储不可用。最终确定入口时同步检查关于面板的密度，避免加入过长的设置区。

### 6.5 后续视觉选项（暂缓）

| 效果 | 价值 | 暂缓原因／启用条件 |
| --- | --- | --- |
| 选中描边 | 边界明确，少改原色 | 增加后处理成本，合批后需按结构选择；先验证性能与细小结构效果 |
| 环境遮蔽阴影 | 加强凹凸和空间层次 | 增加渲染负担，可能将细结构压暗；应为可选项 |
| 透明／X 光观察 | 观察内部与周围关系 | 排序、重叠和深度理解可能混乱；必须与准确的显隐和拾取配合 |
| 写实纹理、泛光、景深 | 演示氛围增强 | 纹理需要可靠来源和许可；泛光／景深可能遮蔽学习细节，不列入首期 |

### 6.6 视觉验收

- 男女模型 × 三种预设 × 全身／单器官／分离／总览，保留统一视角截图对比。
- 在不同背景下检查骨骼、肌肉、血管、神经及深色器官；原色与选中状态可辨。
- 对正、侧、背、斜视及自动旋转检查高光、暗面与亮度变化。
- 配置即时生效，不重新下载模型或重建整个场景；语言切换、模型切换与刷新后偏好正确。
- 桌面和手机布局不遮挡模型；新控件支持键盘、焦点状态和可访问名称。
- 记录新增配置对帧耗时的影响。无视觉收益或有明显性能退化的方案不默认启用。
